# Скрипты аудита lapetitebloom.com

Инструменты для обхода трёх языковых версий магазина и сборки отчёта.
Отчёт лежит уровнем выше (`../README.md`, `../report.html`).

## Как устроен сайт

- Laravel, движок Fenix. Три локали, язык задаётся **префиксом URL**:
  `pl` — без префикса, `ua` — `/ua/...`, `en` — `/en/...`.
- Валюта задаётся отдельно, POST на `/settings/locale` (`_token`, `locale`, `currency`).
  Ответ — JSON вида `{"location": "https://lapetitebloom.com/en"}`.
- До запуска витрина закрыта заглушкой «Opening Soon» для анонимных посетителей.
  Сессия администратора её снимает, поэтому обход идёт под логином.
- Неочевидное: **непрефиксные URL следуют локали, сохранённой в сессии**. Поэтому
  на каждую локаль заводится отдельная сессия, иначе польские страницы приходят
  на украинском.

## Учётные данные

В коде их нет. Перед запуском:

```sh
export LPB_ADMIN_EMAIL='...'
export LPB_ADMIN_PASS='...'
```

## Порядок запуска

```sh
pip install requests beautifulsoup4 lxml

python3 bootstrap.py                    # проверка логина, заглушки и трёх локалей
python3 crawl.py                        # 54 URL × 3 локали → raw/{locale}/*.{html,txt,json}
python3 analyze.py                      # кросс-локальный диф → cmp/*.md, analysis.{json,md}
python3 build_report.py findings/ ..    # сборка отчёта из находок агентов
```

`raw/` и `cmp/` в git не коммитятся — это 30 МБ промежуточных снимков.

## Что делает каждый скрипт

| Скрипт | Что делает |
|---|---|
| `bootstrap.py` | Логинится в `/acp`, проверяет, снимает ли сессия заглушку, и что все три локали отдают правильный `<html lang>` |
| `crawl.py` | Обходит список путей в трёх локалях, сохраняет HTML, видимый текст и метаданные, включая объект `window.FenixTranslations` с UI-строками |
| `analyze.py` | Складывает три локали одной страницы в `cmp/<slug>.md` и ищет автоматически: lorem ipsum, заглушки, кириллицу не по локали, строки, дословно совпадающие с польскими, расхождения ключей `FenixTranslations` |
| `build_report.py` | Сливает JSON-находки агентов, снимает дубли, сортирует по severity и собирает `README.md` и `report.html` |

`analyze.py` даёт сырой сигнал с ложными срабатываниями (бренды, артикулы, размеры
одинаковы во всех локалях по делу) — он нужен как подсказка, а не как готовый список.
