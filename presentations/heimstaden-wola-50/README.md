# Квартиры Heimstaden от 50 м² в районе Воля (Варшава)

Презентация на русском языке по всем предложениям Heimstaden в варшавском
районе Воля площадью от 50 м². Цены в презентацию намеренно не включены.

## Результат подбора

Каталог Heimstaden по Варшаве на 26.08.2026 — 159 квартир, из них 24 в районе
Воля (все по одному адресу, Grzybowska 49). Порог «от 50 м²» проходит **одна**
квартира: **m0104, 50,99 м², 2 комнаты**
([объявление](https://oferty.heimstaden.pl/warszawa/offers/42216-2-pokojowe-5099-m2-balkon-internet-w-cenie-bezposrednio)).

Остальные квартиры дома меньше: 2-комнатные 40,7–41,8 м², студии 30,3–38,9 м².

## Файлы

| Файл | Что это |
|---|---|
| `Kvartiry-50m2-Wola-Heimstaden.pptx` | презентация, 13 слайдов |
| `Kvartiry-50m2-Wola-Heimstaden.pdf`  | та же презентация в PDF |
| `grzybowska-49.html`                 | веб-версия одной страницей, фотографии встроены — открывается без скачивания |
| `photos/`                            | все 8 фотографий объявления, включая план квартиры |
| `data.json`                          | исходные данные подбора (все 24 предложения на Воле) |
| `build.js`                           | генератор презентации |
| `build_page.py`                      | генератор веб-версии |

## Как пересобрать

```bash
npm install pptxgenjs
node build.js        # презентация
python3 build_page.py  # веб-версия
```

## Источник данных

Каталог `oferty.heimstaden.pl`; листинг забирается из
`https://api.flater.pl/newsearch?url=https://oferty.heimstaden.pl&page=N`
(параметр `url` со схемой обязателен — без него API отдаёт другой инстанс).
Площадь квартир указана в заголовках предложений, поэтажный план — в галерее.
