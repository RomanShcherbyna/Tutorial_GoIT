# Общий разбор правок

Тот же документ «Что менять на сайте», но ответы и комментарии видят все, кто
открыл ссылку. Нужен, когда правки разбирают несколько человек и результат
уходит программистам: в скачанном файле пометки остаются в браузере того, кто
их поставил, и коллега их не увидит.

## Что внутри

- `server.mjs` — сервер. Зависимостей нет, только Node 22.
- `public/index.html` — сама страница, собранная из чек-листа.
- `Dockerfile`, `railway.json` — чтобы развернуть.

## Запустить у себя

```sh
node server.mjs            # откроется на :3000
PORT=8080 node server.mjs  # или на своём порту
```

Данные лягут в `./data/state.json`.

## Развернуть на Railway

1. New Project → Deploy from GitHub repo → выбрать этот репозиторий.
2. Settings → **Root Directory**: `checklist/server`. Без этого Railway соберёт
   корень репозитория и не найдёт `Dockerfile`.
3. Variables → добавить `ACCESS_PASSWORD` — общий пароль на вход. Если не
   задать, страница открыта всем, у кого есть ссылка.
4. **Data → Add Volume, путь `/data`.** Это обязательный шаг: без тома файловая
   система пропадает при каждом обновлении, и весь разбор вместе с ней.
5. Settings → Networking → Generate Domain. Полученную ссылку раздать команде.

Проверка после деплоя: `https://<домен>/healthz` должен ответить
`{"ok":true,...}`.

## Переменные окружения

| переменная | по умолчанию | зачем |
|---|---|---|
| `PORT` | `3000` | Railway подставляет свой |
| `DATA_DIR` | `./data` | каталог состояния, на Railway — `/data` |
| `ACCESS_PASSWORD` | пусто | общий пароль; пусто — вход свободный |
| `PAGE_FILE` | `./public/index.html` | если страница лежит в другом месте |

## Как забрать ответы

`GET /api/export` отдаёт файл `otvety.json` — решения и вся переписка по каждой
правке. Его можно прислать мне в чат: я разберу и перепишу список.

## Обновить документ

Страница собирается из чек-листа; после правок в данных:

```sh
cd checklist
python3 build_workorder.py data/checklist.json data/translations.json pages Chto-menyat-na-sayte.html
python3 server/refresh.py
```

`refresh.py` кладёт свежую страницу в `public/index.html` и добавляет строку,
которая включает общий режим. Ответы при этом не теряются: они лежат в
`state.json` отдельно и привязаны к номерам правок.

## Про пароль

Пароль один на всех и хранится в cookie — это забор от случайного прохожего, а
не разграничение прав. Кто угодно вошедший может писать и удалять реплики.
Для разбора внутри команды этого достаточно; выкладывать документ в открытый
доступ не стоит — в нём готовые тексты страниц и реквизиты компании.
