# Чек-лист правок lapetitebloom.com

Внутренняя страница для команды: что починить на сайте по трём языковым версиям,
где это лежит и какой текст туда вставить. Отметки «готово» общие — их видит каждый,
у кого есть ссылка.

## Запуск локально

```bash
cd checklist
pip install -r requirements.txt
python3 app.py
```

Откроется на <http://localhost:8000>. Порт меняется переменной `PORT`.

## Что внутри

| Путь | Что это |
|---|---|
| `/` | сам чек-лист |
| `/api/checklist` | задачи вместе с текущими статусами |
| `/api/state/{id}` | `POST` — поменять статус или комментарий |
| `/api/progress` | сколько закрыто |
| `/documents/…` | скачать документы |
| `/health` | проверка живости, её же дёргает Railway |

## Данные

- `data/checklist.json` — задачи. Пересобирается из аудита:
  ```bash
  python3 build_data.py ../audit/lapetitebloom/findings.json data/checklist.json claims.json
  ```
- `data/state.db` — SQLite со статусами. **В git не хранится** и переживает
  перезапуск процесса, но не пересоздание контейнера.
- `documents/originals/` — присланные `.docx`, отдаются на скачивание как есть.
- `documents/txt/` — те же документы текстом, для поиска и сверки.

## Деплой на Railway

В репозитории уже лежат `Procfile` и `railway.json` — Railway поднимет сервис
командой `uvicorn app:app`, проверяя `/health`.

Два момента, о которых стоит знать заранее:

1. **Корень проекта.** Railway должен собирать папку `checklist/`, а не корень
   репозитория — в корне лежит несвязанный Telegram-бот. В настройках сервиса
   укажите Root Directory = `checklist`.
2. **Статусы и диск.** `data/state.db` лежит на диске контейнера, а он у Railway
   эфемерный: при передеплое отметки обнулятся. Чтобы этого не было, подключите
   Volume и смонтируйте его в `/app/data`, либо задайте `CHECKLIST_DB` путём
   внутри тома.

## Доступ

Логина нет: ссылка и есть доступ. Это нормально для внутренней страницы, но
означает, что публиковать её в открытых каналах не стоит — там лежат рабочие
тексты и документы магазина. Кто менял статус, видно: имя вводится один раз и
сохраняется рядом с отметкой.
